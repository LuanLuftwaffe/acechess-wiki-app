# PARITY_BUGS.md — Nhật Ký Sai Lệch Hành Vi (Tool Gốc vs App Mới)

| ID | Kịch bản / Vị trí | Mức độ | Mô tả sai lệch | Nguyên nhân | Giải pháp đề xuất | Trạng thái |

| **BUG-001** | `GameStateDetector` / Preflight Điều kiện 1b | Lỗi sai giao diện / phân loại | App mới đọc `versionName` từ `PackageManager` (`1.1.1`), trong khi tool gốc đọc phiên bản nội dung VFS từ `0.info` (`1.9.2.4`). Dẫn đến app mới báo game là 1.1.1 và chặn bản vá sai lý do. | Giả định sai rằng `PackageInfo.versionName` phản ánh phiên bản game. Thực tế Tencent cố định `versionName="1.1.1"` và quản lý phiên bản qua VFS `QtsVFSCache/packages/0/0.info`. | Sửa `GameStateDetector` để đọc phiên bản game từ VFS `0.info` (fallback sang `QtsPackageConfig.json`, marker `hokvi_applied.json`, hoặc `manifest.gameVersion`). Giữ nguyên kiểm tra chặn lệch bản vá. | **ĐÃ SỬA** (Commit: `2e729cb7`) |
| **BUG-002** | Kịch bản S7 / Quản lý Nhạc (`MusicScreen`) | Nhỏ / Khác biệt dữ liệu | Khi nạp nhạc vào game, tool gốc nạp bài hát mặc định `ngth.mp3` (5.2 MB, nhóm HOKVI), trong khi app mới nạp placeholder `sample_theme.mp3` (21 byte). Dẫn đến `titles.txt` và file nhạc trên máy bị lệch so với tool gốc. | App mới chưa đóng gói tệp âm thanh mặc định `ngth.mp3` của tool gốc mà dùng bài mẫu giả lập. | Đóng gói bài `ngth.mp3` vào assets của app mới và đồng bộ danh sách nhạc mặc định ban đầu khớp tool gốc. | **CHỜ DUYỆT SỬA** |
| **BUG-003** | Kịch bản S8 / ShowTime (`ShowTimeScreen`) | Mất dữ liệu / Lỗi quyền | `ShowTimeRenderer.kt` ghi trực tiếp qua `FileOutputStream` vào `/sdcard/Android/data/com.tencent.tmgp.osgame/files/HOKVI/showtime/`. Trên Android, app không có quyền ghi trực tiếp vào thư mục của app khác mà không qua Shell/Shizuku, dẫn đến 13 file RGBA không thể ghi vào game. Tool gốc dùng Shizuku/root shell nên ghi thành công 100%. | `ShowTimeRenderer` thiếu cơ chế chuyển giao lệnh ghi file qua `ShellResolver` / `Shizuku`. | Cập nhật `ShowTimeRenderer` để kết xuất ảnh ra cache nội bộ của app, sau đó gọi `ShellResolver` / `Shizuku` để copy sang thư mục game. | **CHỜ DUYỆT SỬA** |
