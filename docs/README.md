# Trung Tâm Tài Liệu Dự Án (Documentation Central)

Nơi lưu trữ toàn bộ tài liệu đặc tả, kiến trúc, phân tích kỹ thuật và nhật ký thay đổi của dự án Rebuild APK.

## Cấu trúc thư mục:
- `specs/`: Đặc tả yêu cầu, thiết kế giao diện, thông số font chữ & cỡ chữ (ví dụ: `specs/BANNER_STYLE_SPECS.md`).
- `reverse-engineering/`: Ghi chú về luồng thực thi Smali, logic In-App Billing, cơ chế nạp menu navigation drawer.
- `handoffs/`: Biên bản bàn giao tiến độ giữa các phiên làm việc và giữa các AI Agent.
