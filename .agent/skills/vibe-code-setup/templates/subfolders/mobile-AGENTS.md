# Mobile Module Scope & Agent Rules

## Phạm vi (Scope)
- Thư mục này chứa mã nguồn ứng dụng di động (iOS / Android), sử dụng Flutter, React Native hoặc Native platform.

## Những điều AI BẮT BUỘC tuân thủ:
1. **Chỉ code ứng dụng Mobile:** Quản lý navigation, state, screen layouts, mobile permissions, push notifications phía thiết bị.
2. **Tuyệt đối cấm:**
   - Không can thiệp mã nguồn web frontend hoặc backend.
   - Không sửa các file cấu hình signing/keystore trừ khi có chỉ định rõ ràng.
