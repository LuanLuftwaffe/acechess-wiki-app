# .codex Configuration Center

Thư mục này chứa cấu hình dành riêng cho **OpenAI Codex**:

- `commands/`: Các lệnh điều khiển chuyên dụng cho Codex.
- `hooks/`: Các hook kiểm tra định dạng và chất lượng mã nguồn.
- `plans/`: Kế hoạch refactoring và testing.
- `policies/`: Chính sách code style và hiệu năng.
- `references/`: Tài liệu tham khảo.
- `rules/`: Các quy chuẩn refactoring và test-driven development.
- `skills/`: Các skill riêng của Codex.
