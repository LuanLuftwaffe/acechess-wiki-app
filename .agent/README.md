# .agent / .agents Configuration Center

Thư mục này chứa cấu hình và workflow dành cho **Google Antigravity Agent Harness**:

- `workflows/`: Quy trình kiểm thử, security audit và E2E pipeline.
- `skills/`: Các skill riêng được đăng ký cho Antigravity.
- `rules/`: Quy tắc phối hợp đa agent, xác minh bằng chứng (Evidence-Based Verification), và trung thực trạng thái.
