# .claude Configuration Center

Thư mục này chứa cấu hình nâng cao dành riêng cho **Claude Code**:

- `commands/`: Các lệnh slash tùy chỉnh (như `/review`, `/deploy`).
- `hooks/`: Các script hook kiểm tra tính toàn vẹn (như `check-root-hygiene`).
- `plans/`: Kế hoạch công việc và lộ trình do Claude lập.
- `policies/`: Các chính sách bảo mật và chất lượng code.
- `references/`: Tài liệu tham khảo kỹ thuật và nghiệp vụ.
- `rules/`: Các luật chi tiết (`no-root-pollution.md`, `clean-code.md`).
- `skills/`: Các skill riêng biệt của Claude Code.
